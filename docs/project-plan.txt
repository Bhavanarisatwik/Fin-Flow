PROJECT SPECIFICATION: FINFlow - Personal Investment & Debt Management Platform
1. EXECUTIVE SUMMARY
FinFlow is a comprehensive personal finance mobile application targeting Indian users (INR currency) that combines automated budgeting, investment tracking, loan management, and long-term wealth projection. The app implements a sophisticated "Three Bracket System" with dynamic allocation algorithms, EMI management, and compound interest projections.
2. CORE FINANCIAL MODEL
2.1 The Three Income Brackets
Users are classified into tiers based on monthly income:
Bracket 1 (Entry): ₹15,000 - ₹25,000/month (Starting: ₹25,000)
Bracket 2 (Mid): ₹50,000 - ₹75,000/month (Starting: ₹75,000)
Bracket 3 (High): ₹1,00,000+/month (Starting: ₹1,00,000)
Salary Progression Logic:
Annual increment: 10% fixed (compounding)
Age range: 21-60 years (40-year projection)
Formula: Salary_Year_N = Starting_Salary × (1.10)^(N-1)
Example: Bracket 1 at Age 30 = ₹58,949/month; Age 60 = ₹10,28,619/month
2.2 Dynamic Budget Allocation Rules
BRACKET 1 (₹25K start, No Emergency Fund allocation):
Needs: 53% (Rent 28%, Food 11%, Utilities 6%, Transport 5%, Mobile 3%)
Wants: 27% (Dining 6%, Entertainment 5%, Shopping 5%, Personal Care 4%, Education 3%, Travel 2%, Gifts 1%, Misc 1%)
Investments: 20%
Emergency Fund: 0% (postponed until income rises)
BRACKET 2 (₹75K start):
Needs: 50% (Rent 25%, Food 9%, Utilities 6%, Transport 7%, Mobile 3%)
Wants: 20%
Emergency Fund: 5% (accumulated separately until 6-month buffer reached)
Investments: 25%
BRACKET 3 (₹1L+ start):
Needs: 45% (Rent 20%, Food 9%, Utilities 6%, Transport 7%, Mobile 3%)
Wants: 20%
Emergency Fund: 10%
Investments: 25%
Absolute Constraint: Investment allocation must never drop below 10% regardless of loan obligations.

3.3 Corpus Calculation Algorithm

compound_monthly(investment_monthly, months, monthly_rate, annual_step_up=0.10):
    corpus = 0
    current_sip = investment_monthly
    projections = []
    
    for month in range(1, months + 1):
        # Annual SIP step-up (if not first month)
        if month % 12 == 1 and month > 1:
            current_sip *= (1 + annual_step_up)
        
        # Compound previous corpus + new investment
        corpus = (corpus + current_sip) * (1 + monthly_rate)
        
        projections.append({
            "month": month,
            "age": 21 + (month-1)/12,
            "invested": current_sip,
            "corpus": round(corpus, 2),
            "total_invested": sum of all SIPs till date
        })
    
    return projections

4.2 EMI Calculation (Reducing Balance)
function calculateEMI(principal, annualRate, years) {
    const p = principal;
    const r = annualRate / (12 * 100);  // monthly interest rate
    const n = years * 12;               // total months
    
    const emi = (p * r * Math.pow(1 + r, n)) / (Math.pow(1 + r, n) - 1);
    return emi;
}

function generateAmortization(principal, rate, years, startDate) {
    const emi = calculateEMI(principal, rate, years);
    let balance = principal;
    const schedule = [];
    
    for(let month = 1; month <= years * 12; month++) {
        const interest = balance * (rate / 100 / 12);
        const principal_paid = emi - interest;
        balance -= principal_paid;
        
        schedule.push({
            month: month,
            payment_date: addMonths(startDate, month),
            emi: emi,
            principal_component: principal_paid,
            interest_component: interest,
            balance: Math.max(0, balance)
        });
    }
    return schedule;
}

4.3 Dynamic Budget Recalculation with Loans
When user adds a loan, recalculate allocations:

Valid DTI (Debt-to-Income) Limits:
- Bracket 1: Max 30%
- Bracket 2: Max 40%  
- Bracket 3: Max 50%

Recalculation Priority Order (when EMI introduced):
1. Reduce Wants (minimum survival mode: 10% of income)
2. Reduce Needs (compression: max 10% reduction)
3. Reduce Investments (floor: 10% of income)
4. If still negative: HIGH DEBT WARNING (block new loans)

Example (Bracket 1, ₹25K income, ₹6,608 Education Loan EMI):
- Original: Needs ₹13,250 (53%), Wants ₹6,750 (27%), Invest ₹5,000 (20%)
- With Loan: Needs ₹11,250 (45%), EMI ₹6,608 (26%), Invest ₹3,500 (14%), Wants ₹3,642 (15%)
4.4 Loan Buffers (Emergency Fund Additions)
Maintain separate liquid buffers:
Home Loan: 6 months EMI
Car Loan: 3 months EMI
Personal Loan: 3 months EMI + Aggressive prepay priority
Education Loan: 0 months (during study), 3 months after
4.5 Prepayment vs Investment Optimizer
Algorithm:
effective_loan_rate = nominal_rate × (1 - tax_benefit)

if effective_loan_rate > investment_return:
    action = "PREPAY"
elif effective_loan_rate < (investment_return - 2%):
    action = "INVEST"
else:
    action = "HYBRID" (50/50 split)

Examples:
- Personal Loan 15%: Effective 15% > 12.25% → PREPAY
- Home Loan 8.5% with 30% tax bracket: Effective 5.95% < 12.25% → INVEST
4.6 Debt Freedom Protocol
When loan is closed:
30% of freed EMI → Emergency Fund (until 12-month buffer)
40% → Restore Investment allocation to bracket target
30% → Lifestyle improvement (Wants) or accelerate other loans

8. BUSINESS RULES & ALGORITHMS
8.1 Allocation Recalculation (Pseudo-code)

function recalculateBudget(user, newLoanEMI = 0):
    income = user.current_salary
    bracket = user.income_bracket
    
    // Base percentages
    if bracket == 1:
        needs_pct = 0.53; wants_pct = 0.27; invest_pct = 0.20; emrg_pct = 0
    elif bracket == 2:
        needs_pct = 0.50; wants_pct = 0.20; invest_pct = 0.25; emrg_pct = 0.05
    else:
        needs_pct = 0.45; wants_pct = 0.20; invest_pct = 0.25; emrg_pct = 0.10
    
    // Apply loan compression
    if newLoanEMI > 0:
        dti = newLoanEMI / income
        
        // Priority order for compression
        available_for_wants = income * wants_pct
        excess = newLoanEMI - (income - (income * (needs_pct + invest_pct + emrg_pct)))
        
        if excess > 0:
            // Reduce wants first
            wants_reduction = min(available_for_wants - (income * 0.10), excess)
            wants_pct -= wants_reduction / income
            excess -= wants_reduction
            
        if excess > 0:
            // Reduce needs (max 10% compression)
            max_needs_cut = income * 0.10
            needs_reduction = min(max_needs_cut, excess)
            needs_pct -= needs_reduction / income
            excess -= needs_reduction
            
        if excess > 0:
            // Reduce investments (floor 10%)
            min_invest = 0.10
            current_invest = income * invest_pct
            max_invest_cut = current_invest - (income * min_invest)
            invest_reduction = min(max_invest_cut, excess)
            invest_pct -= invest_reduction / income
            excess -= invest_reduction
            
        if excess > 0:
            return ERROR "Loan not affordable - Exceeds 10% investment floor"
    
    return {
        needs: income * needs_pct,
        wants: income * wants_pct,
        invest: income * invest_pct,
        emergency: income * emrg_pct,
        emi: newLoanEMI
    }

function calculateTaxBenefits(user, fy_year):
    total_benefit = 0
    
    // Section 80C (₹1.5L limit)
    eighty_c_contributions = [
        user.elss_investments,
        user.home_loan_principal,
        user.ppf_contributions,
        user.lic_premiums
    ]
    eighty_c_used = min(sum(eighty_c_contributions), 150000)
    tax_saved_80c = eighty_c_used * user.tax_slab // 0.05, 0.20, or 0.30
    
    // Section 24 (Home Loan Interest - ₹2L limit)
    home_loan_interest = sum of interest paid on home loans
    twenty_four_used = min(home_loan_interest, 200000)
    tax_saved_24 = twenty_four_used * user.tax_slab
    
    // Section 80E (Education Loan - No limit)
    edu_loan_interest = sum of education loan interest
    tax_saved_80e = edu_loan_interest * user.tax_slab
    
    return {
        total_saved: tax_saved_80c + tax_saved_24 + tax_saved_80e,
        breakdown: {
            "80C": tax_saved_80c,
            "24": tax_saved_24,
            "80E": tax_saved_80e
        },
        remaining_80c_limit: 150000 - eighty_c_used,
        remaining_24_limit: 200000 - twenty_four_used
    }
